# 🎓 Student Registration Form

A simple and responsive **Student Registration Form** built using **HTML**. This project demonstrates how to create a basic registration form with different HTML form elements.

## 🚀 Live Demo

🔗 https://singhwatsalraj-arch.github.io/Student-Registration-form/

## ✨ Features


- 👤 First Name & Last Name
- 📧 Email Address
- 🔒 Password
- 🚻 Gender Selection
- 📚 Course Dropdown
- 🎂 Date of Birth
- 📱 Phone Number
- 🏠 Address
- ✅ Register Button
- 🔄 Reset Button

## 🛠️ Technologies Used

- HTML5

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/singhwatsalraj-arch/Student-Registration-form.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
