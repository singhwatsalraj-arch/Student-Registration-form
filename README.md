# 🎓 Student Registration Form

A simple and user-friendly Student Registration Form built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

[Click Here to View Student Registration Form](https://singhwatsalraj-arch.github.io/Student-Registration-form/)

## 📌 About The Project

The Student Registration Form is a web-based project designed to collect student information through an online registration form.

This project helps beginners understand HTML forms, CSS styling, and JavaScript form validation.

## ✨ Features

- Student ID input
- Full Name field
- Email address
- Password field
- Gender selection
- Course selection
- Date of Birth
- Phone Number
- Address field
- Register button
- Reset button
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5 – Structure of the webpage
- CSS3 – Styling and layout
- JavaScript – Form validation and interactivity
